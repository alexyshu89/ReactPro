# LESSON-7 - Сборка приложения

Ветка: lesson-6

## Запуск

cd build-hw
npm install

app:dev - сборка с помощью esbuild директории app для dev
app:build - сборка с помощью esbuild директории app для prod
lib:dev - сборка с помощью esbuild директории lib для dev
lib:build - сборка с помощью esbuild директории lib для prod
swc:lib - сборка с помощью swc директории lib

4. Выполнено часть доп задания (Использование swc для сборки библиотеки)
